
  # Interview Panel Booking Platform

  This is a code bundle for Interview Panel Booking Platform. The original project is available at https://www.figma.com/design/EnxdMh8g5LicTMeOvzsgZS/Interview-Panel-Booking-Platform.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the Next.js development server.

  Run `npm run build` to create a production Next.js build.

  The original Vite entry is still available with `npm run dev:vite` and `npm run build:vite`.
